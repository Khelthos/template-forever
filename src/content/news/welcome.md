Welcome! This article shows what a news item written in Markdown looks like.

## What you'll find on the site

- **News:** announcements and event recaps.
- **Roster:** guild members with class, specialization and rank.
- **Guides:** preparation and strategy for dungeons and raids.

## Available formatting

You can use *italics*, **bold**, [links](https://www.markdownguide.org/basic-syntax/), lists, tables, quotes and code blocks:

```text
/join guild
```

To write a new news item create a `.md` file in the `src/content/news/` folder: the README explains how.
