This is a **demo guide**, not an official game guide. Copy it into a new file and replace the generic text with information about the dungeon you want to describe.

## Introduction

Describe the dungeon in a few lines: where it is, which level range it is meant for and why it is worth running with the guild.

## Preparation

### Gear

List the most useful stats for each role and any recommended gear. Avoid strict requirements for guild groups.

### Consumables

- Food and drink to recover between fights.
- Potions for emergencies.
- Reagents for the classes that need them.

## Bosses and encounters

### First encounter

Describe the main mechanics in order of importance. For each mechanic explain **what happens**, **who has to react** and **how**.

### Second encounter

Keep lists short: nobody reads long paragraphs in the middle of a fight.

## Group composition

| Role | Main task | Tip |
| --- | --- | --- |
| Tank | Hold the enemies' attention | Mark the target before each pull |
| Healer | Keep the group alive | Manage mana between pulls |
| DPS | Defeat the enemies | Follow the kill order |

## Final tips

> Write down the most common mistakes you have seen guild groups make and how to avoid them.
